Storage Estimator

Project Purpose

The Storage Estimator is a simple Python program that converts storage sizes from gigabytes (GB) to megabytes (MB) and terabytes (TB).

How to Run the Program

Install Python on your computer.

Open the project folder in VS Code.

Open the terminal.

Run the following command:

python storage_estimator.py

Enter the storage size in GB when prompted.

Example Input

Enter storage size in GB: 2048

Example Output

Storage Conversion Results
--------------------------
Storage in GB: 2048.0
Storage in MB: 2097152.0 MB
Storage in TB: 2.0 TB

Program completed successfully!
